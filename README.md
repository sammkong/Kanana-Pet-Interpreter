## 프로젝트 소개

**“반려동물 속마음을 AI가 대신 말해준다면 어떨까?”**

이 프로젝트는 반려동물 사진을 바탕으로 표정과 분위기를 해석하고 감정을 추정한 뒤, 강아지/고양이 페르소나 말투로 **텍스트와 음성을 함께 생성하는 멀티모달 AI 서비스**입니다.

> **"더욱 똑똑하게 답하며, 더욱 풍부한 감정표현을 향한 Kanana-o"**

라는 슬로건에 맞춰,  
Kanana-o만이 가진 **멀티모달 응답과 감정 표현 강점**을 서비스 경험 안에 자연스럽게 녹여보고자 했습니다.

단순 이미지 분석보다, 사용자가 실제로 **귀엽고 자연스럽다고 느끼는 AI 경험**을 만드는 데 집중했습니다.

프로젝트를 진행하며 **AI 응답 자연스러움 평가**, **페르소나 일관성 테스트**, **Prompt Engineering 반복 개선**, **사용자 경험 중심 응답 품질 조정** 과정을 경험할 수 있었습니다.

## Prompt Engineering & UX 개선 과정

프로젝트를 진행하며 Prompt를 반복적으로 수정했습니다.

### 1. 긴 응답에서 페르소나 붕괴

자유 생성 방식에서는 응답이 길어질수록 `~멍!`, `~냥.` 말투 일관성이 쉽게 무너졌습니다.

> 첫 문장은 강아지 말투인데 뒤 문장은 **일반 설명체**로 바뀌거나, **감정 표현이 어색하게 반복**되는 현상이 자주 발생했습니다.

### 2. Few-shot Prompt 추가

삐진 강아지, 귀찮은 고양이 같은 예시 대사를 **few-shot**으로 추가해 말투 패턴을 더 안정적으로 유도했습니다.

이후 반복적으로 테스트를 진행하면서, 초반 문장만 캐릭터 말투를 유지하고 후반부에서 일반 설명체로 바뀌는 현상이 이전보다 줄어드는 것을 확인할 수 있었습니다.

### 3. 말투 제약 + 후처리 적용

문장 ending 제한과 응답 길이 제약을 추가했고, 최종적으로 `_enforce_pet_ending()` 후처리를 통해 페르소나 일관성을 한 번 더 보정했습니다.

여러 입력 상황으로 테스트를 계속해서 진행하며, 감정 표현이 과하게 반복되거나 말투가 중간에 깨지는 문제를 수정해나갔습니다.

### 4. 자연스러움 vs Consistency Trade-off

Consistency를 강하게 제한하면 응답이 부자연스러워지고, 자연스러움을 우선하면 캐릭터성이 약해진다는 점이 보였습니다.

결국 최종적으로는

> 단순 정보 전달보다, **감정 표현과 캐릭터 일관성을 우선하는 방향**

으로 서비스를 개선했습니다.

왜냐하면 이 서비스에서 중요한 건 “정확한 분석”보다

- 귀엽다고 느껴지는 경험
- 반려동물과 대화하는 느낌
- 캐릭터 몰입감

이라고 판단했기 때문입니다.

## 이 프로젝트를 통해 느낀 점

여러 번의 테스트를 진행하면서, 동일한 모델이라도 Prompt 구조나 응답 길이에 따라 **사용자가 느끼는 자연스러움**이 크게 달라진다는 점을 직접 확인할 수 있었습니다.

특히 **“이 말투가 정말 자연스러운가?”**, **“분석한 감정이 실제로 잘 반영됐는가?”**를 사용자 입장에서 계속 확인하며 Prompt와 후처리를 반복적으로 수정해나갔고, 단순히 정확한 응답보다 **반려동물의 감정이 얼마나 자연스럽고 생생하게 전달되는지**가 사용자 경험에 더 큰 영향을 준다는 점도 체감했습니다.
